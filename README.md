# Hosihikari.Bindings.LeviLamina

[English](README.md) | [简体中文](README.zh_hans.md)

The LeviLamina LLAPI surface for the Hosihikari bindings: a CI-generated native-style **Interop**, a hand-written .NET **Idiomatic** layer, and the native **BindingShim**.

## Boundary

- `Hosihikari.Bindings.LeviLamina.Interop` is generated by `Hosihikari/Bindings.Generator` from the versioned IR. It mirrors LLAPI declarations and keeps `nint`/opaque handles; it is committed and checked by a CI regeneration diff.
- `Hosihikari.Bindings.LeviLamina` is the hand-written .NET layer: properties, events, operators, indexers, constructors, and the service-thread scheduler. It is not generated.
- `native/BindingShim/` is the C ABI projection compiled with LeviLamina's xmake/LLVM toolchain. It does not host the CLR; the HostingShim is a separate layer.
- The first slice is **LLAPI + the reachable MCAPI closure**; the full Bedrock surface follows in the shared `Hosihikari.Bindings.Bedrock` package.

## Status

Scaffold. The two managed projects and the solution exist; generated sources will land under `src/.../Generated/`. The native BindingShim target is documented but not implemented yet.

## Build

```shell
dotnet build Hosihikari.Bindings.LeviLamina.slnx -c Release
```

The package version follows the upstream version plus the binding revision (`26.51.7-r0` at scaffold time). The platform matrix for this surface is Windows x64, matching upstream's release/CI support.

## Sibling repositories

- Internal `Hosihikari/Design` repository (private): glossary, ADRs, IR/coverage contract.
- `Hosihikari/Bindings.Ir`: schema, models, reader/writer, validator.
- `Hosihikari/Bindings.Generator`: libTooling frontend and emitters.
